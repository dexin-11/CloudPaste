# Checklist

- [ ] `files` 表新增 `target_type`（默认 `'file'`），SQLite 建表、迁移 `app-v35` 与 `schema.sql` 均已同步，旧库升级后可用
- [ ] `APP_SCHEMA_VERSION` 已提升，迁移可在旧库上重复安全执行（幂等）
- [ ] `POST /api/fs/create-share` 接收并透传 `password/expires_in/max_views/remark/slug`
- [ ] 后端可对**文件夹**创建分享记录（`target_type='folder'`，指向目录前缀），不再拒绝目录
- [ ] 挂载浏览可对**文件**与**文件夹**生成分享链接，且支持备注/密码/有效期/下载次数/自定义 slug
- [ ] 分享链接支持密码：未验证不返回任何可访问 URL，密码错误返回 401，验证通过可访问
- [ ] 分享链接支持有效期：超过 `expires_at` 返回 410
- [ ] 分享链接支持下载次数上限：达到上限返回 410，且记录被清理
- [ ] 下载计数仅在**实际下载**时 +1；仅打开/预览分享页不计数
- [ ] 文件夹分享的下载次数为**累计**（其内多个文件下载次数累加）
- [ ] 设置了下载上限的分享，其下载入口强制走后端代理，直链无法绕过计数
- [ ] 公开文件夹分享页 `/folder/:slug` 可只读浏览：列目录、进入子目录、单文件预览与下载
- [ ] 文件夹分享的 `path` 越权访问（`..`/绝对路径/编码绕过）被拒绝，无法访问分享根目录之外内容
- [ ] 引用挂载盘的分享在过期/次数用尽后仅删除分享记录，**不删除**网盘中的真实文件/文件夹
- [ ] `/file/:slug` 命中文件夹分享时自动跳转到 `/folder/:slug`
- [ ] 挂载浏览上传弹窗支持「上传并生成分享链接」，可设置密码/有效期/下载次数，上传后展示链接
- [ ] 「上传并生成分享链接」中单个文件分享失败不影响其他文件，且给出提示
- [ ] 独立「文件上传」页已移除：`/upload` 重定向到 `/mount-explorer`，导航不再出现上传入口
- [ ] `siteUploadPageEnabled` 可控制挂载浏览内上传能力（关闭后无上传入口，浏览正常）
- [ ] 管理端「文件管理」展示类型（文件/文件夹）与「最大下载次数」，可编辑分享限制
- [ ] `zh-CN`/`en-US` 文案齐全，无缺失键
- [ ] 前后端构建/静态检查通过，原有文件分享与挂载浏览功能无回归
